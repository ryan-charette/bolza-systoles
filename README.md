# Bolza Systoles

> Work in progress.

A Jupyter notebook for exact systole calculations on Bolza congruence surfaces, together with a genus-eight spectral check.

## Run

```bash
pip install python-flint matplotlib jupyter
jupyter notebook bolza_systoles.ipynb
```

Generated data are saved in `results/` and plots in `images/`.

The exposition, code, and mathematical claims are still being checked and revised.

## References

Mostly based on this paper:	[Bolza quaternion order and asymptotics of systoles along congruence subgroups
](https://arxiv.org/abs/1405.5454)
